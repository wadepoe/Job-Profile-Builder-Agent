# Output Delivery Skill

## When to Use This Skill

Load this skill when the user has approved a job profile draft and is ready to deliver it.

## Step 0: Confirm Output Mode

If the user has not already selected an output mode, ask:

"How would you like to receive the completed job profile?"

Options:
1. **Write directly to SuccessFactors** — creates the profile via API immediately
2. **Export as CSV** — generates a file for bulk import into Job Profile Builder
3. **Document draft** — returns a formatted document for copy-paste or filing

## Mode 1: API Write to SuccessFactors

### Process
1. Assemble the complete profile payload from the approved draft fields.
2. Call the Generic Objects API write tool with the profile payload.
3. On success: return the created profile ID and a confirmation message.
4. On failure:
   - Report the error message exactly as received from the API.
   - Offer CSV export as automatic fallback: "The API write failed. Would you like me to export the profile as a CSV instead? Your approved content is preserved."
   - Do NOT discard the approved content on failure.

### Payload structure
```
{
  "objectType": "JobProfile",
  "externalCode": "{job_code}",
  "jobTitle": "{job_title}",
  "jobFamily": "{job_family}",
  "jobFunction": "{job_function}",
  "jobLevel": "{job_level}",
  "templateId": "{template_id}",
  "sections": [
    {"sectionType": "{section_type}", "content": "{content}"},
    ...
  ]
}
```

## Mode 2: CSV Export

### Format
Generate a CSV with the following columns, one row per profile section:
```
profile_external_code, job_title, job_code, job_family, job_function, job_level, template_id, section_type, section_content, source_annotation
```

### Rules
- Wrap all text values in double quotes
- Escape any internal double quotes by doubling them ("")
- Use UTF-8 encoding
- Include a header row
- One row per section (not one row per profile)

### Delivery
- Return the CSV content as a downloadable file named `{job_code}_job_profile.csv`
- Confirm the file is ready and explain how to import it in SuccessFactors Job Profile Builder

## Mode 3: Document Draft

### Format
Return a clean, human-readable markdown document:

```
# Job Profile: {job_title}

**Job Code:** {job_code}
**Job Family:** {job_family}
**Job Function:** {job_function}
**Job Level:** {job_level}
**Template:** {template_id}

---

## {Section Name}
{section_content}

---

## {Section Name}
{section_content}

---

*Generated by Job Profile Builder Agent | Source annotations available on request*
```

### Delivery
- Present the document in the conversation
- Offer to export as a .txt or .md file if the user needs a downloadable copy

## Post-Delivery Actions

After successful delivery:
1. Confirm the profile has been delivered.
2. Ask if the user wants to link the profile to a job requisition (offer to use `link_requisition_tool`).
3. Offer to generate another profile or start a batch run.
